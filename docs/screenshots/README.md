# CivicFlow screenshot checklist

No screenshots are committed until they have been captured from synthetic local demo data and reviewed for privacy.

Planned public images:

1. Resident request list and SLA indicators
2. Resident submission with map marker and attachment picker
3. Resident progress and public conversation
4. Manager case queue with filters and sorting
5. Manager triage, SLA, and assignment controls
6. Dashboard KPIs, charts, workload, and at-risk table
7. Officer My Cases and quick views
8. Officer public conversation, internal notes, and resolution
9. Administrator category and user management
10. Manager/Administrator audit log
11. Public versus Internal attachment visibility

Before committing an image, remove real names, emails, addresses, case references, tokens, browser profile details, local paths, connection information, Blob identifiers, and unrelated desktop content. Do not manufacture screenshots or imply that a mockup is a running application.
